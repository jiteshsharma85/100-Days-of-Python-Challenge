# Coffee Machine (Procedural)

A command-line coffee machine simulator built with Python using a procedural / functional approach. This is the earlier version of the project — see **Coffee OOps** for the refactored OOP version.

## Features

- Order espresso, latte, or cappuccino
- Coin-based payment with change calculation
- Resource tracking (water, milk, coffee)
- Type `report` to view current stock and total profit
- Type `off` to shut down the machine

## How to Run

```bash
python main.py
```

## Concepts Practiced

- Functions and modular design
- Global state management
- Dictionary lookups
- User input validation
